# ColloquiScuola (prototype)

This app is designed to make school meetings between families and teachers simple, but above all, less chaotic. The app is written entirely in C# using the .NET 10 framework and .NET MAUI packages.
The backend consists of a REST API, also written in C#, which is designed to be paired with a SQL database.

The app stays in an unfinished state, though progress will remain visible.

# ColloquiScuola (prototipo)

Quest'app è dedicata a rendere i colloqui scolastici semplici, ma soprattutto meno caotici. L'app è scritta interamente in C# con il framework .NET 10 e i pacchetti .NET MAUI
Il backend è un API REST scritto in C# che va accoppiato con un database SQL.

L'app rimane in uno stato incompleto, sebbene i progressi restino visibili.
